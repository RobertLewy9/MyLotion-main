## 二、必须能「讲满 2 分钟」的 6 道题

1. **项目总述**：三层架构 + 主链路 8 步（照着架构图讲）。
2. **SSE 全链路**：工具执行 → `onEvent` → 事件队列 → 200ms 编码 → 前端 `type` 分发；为什么不 WebSocket。
3. **Tool Calling 全链路**：schema 定义 → 模型决定 → 服务端执行 → 报错可读回传 → 模型重试。
4. **上下文压缩**：窗口结构、确定性、重写式摘要、失败降级、串行化。
5. **边界题**：「一篇文档能无限写吗」「文档树深到十万级怎么办」——先承认扛不住，再分层给方案。
6. **安全**：危险操作闸门 + 幂等 + RLS 三层防护。

## 五、一个诚实性提醒

项目 README 里写明了「代码由 AI 产出，我负责读懂 → 讲清楚 → 扛住追问」。
简历上写的是「独立完成……三大模块及后端 API」。这两者不矛盾的前提是：**你确实能对每一个决策说出「为什么」**。

面试官不会查代码是谁敲的，只会问：

- 为什么这么设计？换个方案行不行？
- 这里如果出问题，你怎么定位？

**所以判断标准只有一条**：简历上出现的每一个词，你都能用三段式讲满 2 分钟。做不到的，先从简历上删掉，等补上了再加回来。
