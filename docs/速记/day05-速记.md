## 30 秒版（电梯里能说完）

「我做的是 AI 笔记应用。前端 Next.js 加 BlockNote，中间是 Route Handler 加 Agent，底层是 Supabase 的 Postgres 单表自引用加 RLS。AI 用 Vercel AI SDK 驱动 Agent 循环，七个工具全部在服务端执行，工具产生的副作用通过 onEvent 走 SSE 推给前端。删除这类危险操作，模型只能发起、用户确认才真删。」

## 三层，一层一句

| 层 | 一句话 |
|----|--------|
| 前端 | 侧边栏树 / BlockNote 编辑器 / AI 面板。前两个直连 Supabase（受 RLS 管），第三个 POST `/api/ai/chat` |
| 中间 | 鉴权 → 幂等落库 → 拉历史 → 装 messages → `streamText` 调工具 |
| 数据 | 1 张 `documents`，`parentDocument` 自引用，RLS 兜底 |

## 八步口诀：发 → 验 → 拉 → 装 → 想 → 做 → 推 → 收

| 字 | 一步做完 |
|----|----------|
| **发** | POST `/api/ai/chat`，带 `sessionId` + `requestId` |
| **验** | `getUser` 鉴权 → 校验会话归属 → 落库（撞唯一约束 → 409） |
| **拉** | 最近 100 条**未压缩**历史 + 会话摘要 |
| **装** | 系统提示词 + 摘要 + 100 条 + 当前输入（窗口写死，不让模型挑） |
| **想** | `streamText` + 7 tools + `stopWhen` 5 步 |
| **做** | `searchNotes`（ILIKE）→ `archiveNote`，**在服务端执行** |
| **推** | `onEvent` → `eventQueue` → SSE 每 200ms → `data: <json>` + 空行 → 前端按 `type` 分发 |
| **收** | `done` → 落库 assistant + token 统计 → `maybeCompressSession` |

## 三问三答（每句 10 秒）

**工具在哪跑？** 服务端。模型只决定调哪个，执行在 `lib/ai/tools`。
**前端怎么知道变了？** 工具里注入 `onEvent`，副作用上报成事件，走 SSE 推过去，前端按类型刷新。
**手抖点两次？** 同一个 `requestId` 撞唯一约束返回 409，幂等键在服务端兜底。

## 三条「为什么不用 X」

- **SSE 不用 WebSocket**：单向够用、HTTP 不用升级协议、自带重连、代理友好；要双向协同才换。
- **单表自引用不用闭包表**：层级简单、一次拉全量建树 O(n)；深度和量级上来再迁。
- **删除不做直接执行**：模型输出不可信；只发起，用户确认才执行。

## 术语急救（卡住就说这一句）

- **RLS**：安全策略写在数据库里，查询自动带「只能看自己的」。
- **幂等**：同一个请求发多次，效果和发一次一样。
- **副作用**：工具对数据的实际改动。
- **SSE**：服务端单向推的 HTTP 长连接，格式 `data: <json>` 加空行。
- **stopWhen**：Agent 循环的步数上限，防止停不下来。
- **上下文窗口**：一次请求能塞给模型的 token 上限。
