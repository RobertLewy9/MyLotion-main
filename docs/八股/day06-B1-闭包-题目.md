## Part 1 · 概念（各 3 分钟）

**1.** 闭包是什么？它产生的三个条件分别是什么？
> 提示：要能说清「函数 + 词法环境 + 被带出原来的作用域」，只说「函数里面套函数」是半成品。

**2.** 闭包会造成内存泄漏吗？什么情况下才是**真的**泄漏？
> 提示：区分「闭包持有引用」和「这个引用永远不被释放」。

**3.** 闭包和柯里化是什么关系？柯里化到底解决什么问题？
> 提示：柯里化是闭包的一种用法，不是同义词；说清「参数复用 / 延迟执行 / 组合」。

## Part 2 · 手写（10 分钟）

实现一个 `curry`，满足下面三种调用：

```js
const add = (a, b, c) => a + b + c;
const curried = curry(add);

curried(1)(2)(3);   // 6
curried(1, 2)(3);   // 6
curried(1)(2, 3);   // 6
```

- 不要求支持占位符（`curry(fn)(_, 2)`）
- 要求：参数够了就立刻执行，不够就继续返回函数
- 加分：能说出它和 `bind` 的关系（`bind` 是「固定 this + 部分参数」，柯里化是「逐个收参数」）

## Part 3 · 项目落地（5 分钟）

在 MyLotion / Lotion 里挑**一个**闭包，按三段式讲（① 在我项目里干什么 → ② 完整流程 → ③ 为什么用闭包，而不是全局变量或类字段）：

- **A. `createNote` 里的 `createdNoteId`** —— 同一轮对话里防止重复建草稿
- **B. `pendingById`** —— 请求去重：同一篇文档的并发请求共用一个 promise
- **C. `debounce` 的 `timer`** —— 编辑器 `onChange` 防抖后再保存
