## 四、被移出的内容不是永远不学

以下内容仍有价值，但**不属于这 8 场的当前优先级**，放到复盘日或简历真正涉及后再学：

- Node `process.nextTick` 的精确排队顺序、thenable 精确 tick、4ms 定时器饥饿、React 18 自动批处理（nextTick 本身仍作为 Node 微任务例子知道即可）；
- generator 自动执行器手写；
- curry 手写实现与专题（只保留“闭包用途”举例）；
- call/apply/bind 的完整 polyfill（含 `new`、原型链）；
- temperature/top_p、few-shot、结构化 JSON、提示注入、幻觉分类；
- ReAct 论文、planner/reflection、多 Agent 拆分、停止条件分类。

原则：**简历写了、项目用了、面试官可能顺着问的，必须会；面经没有出现且不支撑项目叙事的，先不背。**
