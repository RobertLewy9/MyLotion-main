## 1. 一句话（10 秒）

MyLotion 是一个 AI 笔记应用，用户可以创建、编辑、管理文档，也可以通过 AI 搜索、读取和修改文档。
Supabase 负责认证、数据库和权限，AI Agent 通过工具完成具体操作，工具产生的副作用通过 SSE 推回前端。

## 2. 有哪几块（30 秒）

整体分三层：

1. **前端**：侧边栏文档树、BlockNote 编辑器、AI 面板；
2. **API / Agent 层**：鉴权、组装上下文、调用模型、执行工具；
3. **数据层**：`documents` 单表自引用存文档树，用 RLS 做用户隔离和权限控制。

## 3. 一次请求怎么流（20 秒）

用户输入 → 前端 POST `/api/ai/chat` → 服务端鉴权 → 组装上下文 → 模型决定调工具 →
服务端执行工具并改数据库 → 工具副作用上报 → SSE 推给前端 → 前端刷新或弹确认框。
