# Day 6 · C 轨题解 —— 移动零（Hot 100 · 双指针）

> **归属：Day 6 · C 轨（力扣 / 手撕）**
> 题目文件：`src/interview/move-zeroes.ts`；用例：`test/interview/move-zeroes.test.ts`（7 个）。
> **先自己限时 20 分钟写，再往下看。** 要求原地、O(n) / O(1)。

## 一、题目

把数组里所有 `0` 移到末尾，**非零元素保持相对顺序**；必须**原地修改**，不返回新数组。

```text
输入: [0, 1, 0, 3, 12]
输出: [1, 3, 12, 0, 0]
```

## 二、思路（双指针）

维护两个指针：

- `write`：下一个「非零元素该放的位置」；
- `read`：当前扫描到的位置。

**不变量**：`[0, write)` 全是非零且保持原顺序；`[write, read)` 全是 0。
每遇到一个非零数，就和 `write` 位置交换，然后 `write++`。扫描结束，0 自然都被换到后面。

## 三、参考实现（交换版，一趟）

```ts
export function moveZeroes(nums: number[]): void {
  let write = 0;

  for (let read = 0; read < nums.length; read++) {
    if (nums[read] !== 0) {
      [nums[write], nums[read]] = [nums[read], nums[write]];
      write++;
    }
  }
}
```

**覆盖版**（两趟，少一点交换，但多一次写 0）：

```ts
export function moveZeroes(nums: number[]): void {
  let write = 0;
  for (const n of nums) {
    if (n !== 0) nums[write++] = n;
  }
  while (write < nums.length) nums[write++] = 0;
}
```

## 四、复杂度

- 时间：**O(n)**，每个元素最多被读一次（交换版每个非零元素交换一次）。
- 空间：**O(1)**，只用两个下标。

## 五、易错点

1. **用 `filter` 生成新数组再赋值**：虽然结果对，但面试要求「原地」，而且空间是 O(n)。
2. **从两端往中间交换**：会把非零元素的相对顺序打乱（`[0,2,0,1]` 会变成 `[1,2,0,0]`，顺序错了）。
3. **忘记处理尾部**：覆盖版必须补 0，否则会留下旧值。
4. **`write === read` 时还交换**：结果没错，但可以加 `if (write !== read)` 少一次自交换（不是必须）。

## 六、面试追问

**Q1：为什么交换不会打乱非零元素的顺序？**
因为 `read` 是从左往右扫的，非零元素按遇到的先后写进 `write` 位置，`write` 单调递增，
所以它们的相对顺序和原数组一致。

**Q2：如果要求把 0 放前面、非零放后面呢？**
同样的双指针，只是把判断反过来；或者扫描完反转。核心不变量不变。

**Q3：如果数组是链表呢？**
双指针思路仍然成立，但「原地」意味着只改指针：维护一个「非零链表尾」和一个「零链表尾」，最后拼接，O(n) / O(1)。
