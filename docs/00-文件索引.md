## 命名规则

| 前缀 | 含义 |
|------|------|
| `dayNN-A-` | 第 NN 天 · **A 轨**（MyLotion 项目：讲稿 / 代码） |
| `dayNN-B1-` | 第 NN 天 · **B1 轨**（前端八股） |
| `dayNN-B2-` | 第 NN 天 · **B2 轨**（Agent 开发八股） |
| `dayNN-C-` | 第 NN 天 · **C 轨**（力扣 Hot 100 / 手撕） |
| `dayNN-全轨-` | 第 NN 天 · 跨轨产出（日志、速记） |
| `00-` | 元文档，不属于某一天 |
| `全轨-` / `A-` / `B1-` / `B2-` / `C-` | 全时段参考或考点清单 |

**每个文档第二行都有 `归属：Day N · X 轨`**，先看标题下那一行就不会乱。

3. **拿不准就查本表**：本文件是唯一的总入口。
