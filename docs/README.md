# Lotion 文档索引

> 文档按用途分成 **学习 / 项目 / 面试** 三类，避免根目录继续堆积。

## 学习

| 文件 | 用途 |
|---|---|
| `docs/学习/00-学习计划.md` | 每日 A / B1 / B2 / C 安排与复盘节点 |
| `docs/学习/00-学习策略.md` | 学习路线与取舍原则 |
| `docs/学习/A-技术选型总览.md` | 技术栈、选型理由、替代方案与切换条件 |
| `docs/学习/A-架构总览.md` | Hono + SQLite + Cordis 的架构与主链路 |
| `docs/学习/B1-前端八股考点.md` | 前端八股考纲与进度 |
| `docs/学习/B2-Agent八股考点.md` | Agent / LLM 八股考纲与进度 |
| `docs/学习/C-力扣Hot100题单.md` | **C 轨唯一进度入口**：勾选、错因、打卡流水 |

- `docs/学习/八股/`：每天 B1 / B2 的题纸与答案，按 `dayNN-B1-*`、`dayNN-B2-*` 命名。
- `docs/学习/讲稿/`：需要展开讲的 A 轨技术选型专题。
- `docs/学习/日志/`：当天全轨执行记录，按 `dayNN-全轨-日志.md` 命名。

## 查找规则

1. 学什么、今天做什么：先进 `docs/学习/`。
2. 查项目架构与插件约束：进 `docs/项目/`。
3. 准备简历与目标岗位：进 `docs/面试/`。
4. 力扣进度永远只看 `docs/学习/C-力扣Hot100题单.md`。
5. `docs/垃圾/` 只是本机待删材料，不纳入远端仓库，也不要继续往里放新资料。

## 命名约定

| 前缀 | 含义 |
|---|---|
| `dayNN-A-` | 第 NN 天 · A 轨（技术选型 / 项目架构） |
| `dayNN-B1-` | 第 NN 天 · B1 轨（前端八股） |
| `dayNN-B2-` | 第 NN 天 · B2 轨（Agent 开发八股） |
| `dayNN-全轨-` | 第 NN 天 · 日志与执行记录 |
| `00-` | 学习计划、策略等元文档 |
| `A-` / `B1-` / `B2-` / `C-` / `全轨-` | 全时段参考材料 |
