## D. Tool / Function Calling（面试最常追）

- [ ] ★★★ 工具是怎么「给」模型的：用 JSON schema 描述名字 / 参数 / 用途
- [ ] ★★★ 模型只负责**决定调哪个工具、传什么参数**，真正执行在**服务端**（这点讲错就露馅）
- [ ] ★★★ 工具执行结果怎么回填给模型（tool 消息 / role: tool）
- [ ] ★★ 多个工具怎么选；参数校验失败怎么办；工具报错怎么回传
- [ ] ★★ 工具超时、重试、幂等（同一个工具被重复调用怎么办）
- [ ] ★★ **危险工具的人机确认闸门**（删笔记要先弹确认）
- [ ] ★★★ `tool` / `skill` / `subagent` / `agent` / `MCP` 的区别（携程 / 腾讯云智一面）
- [ ] ★ 工具权限与越权：模型能改库，怎么保证只改自己的数据
