## 节奏规则（2026-10-20 校准 —— 45 天不是每天满配）

> 前 5 天是「题型示范日」，题纸是整卷量；**日常不按那个量走**。

| 规则 | 具体 |
|------|------|
| **每天只走一条八股轨** | B1 / B2 **隔天交替**；内容从各自队列取「下一个没做完的」，不按死日期 |
| **每次 3 题 + 1 题项目落地** | 概念 2 + 场景 1 + 「这条在我项目里怎么落地」1，计时 25 分钟 |
| **整卷只在复盘日** | Day 11 / 18 / 25 / 35 / 42 做整卷题纸（10~15 题），平时不做 |
| **A 轨每天必须有可见增量** | 要么一篇讲稿，要么一个可跑模块 + 用例 —— 不许连续两天只有「读文档」 |
| **连续 2 天没完成 → 降级** | 第 3 天只做 A + C，八股顺延；先保「讲得出」和「写得下」 |
| **45 天是上限不是配额** | 到 Day 42 还没走完，就砍工程化深挖 / 源码泛读，保 A 轨 + ★★★ 八股 + Hot 100 |

## 弹性规则

- 某天没做完 → **整体顺延**，不要跳过；宁可少做一条轨，也别断档
- B2（Agent 八股）在 Day 26-35 会和 A 轨的 AI 阶段重合，**重合部分只算一次时间**，别重复刷
- 四条轨都空着的那天，优先保住 A 轨和 C 轨（讲得出 + 写得下），B1 / B2 可以顺延
- 每个阶段最后一天是**复盘日**（Day 11 / 18 / 25 / 35 / 42），只讲不学新东西
- B 轨 ★★★ 高频条目至少过 **3 遍**（首次学 / 复盘 / 冲刺）。**错题记进 `docs/日志/dayNN-全轨-日志.md`，二刷只重写错题**
- **八股是队列不是配额**：当天没讲完的条目顺延到下一次，不为了「完成日历」硬塞；但**不许跳过**
- **C 轨暂停上新**：欠账（两数之和 / 字母异位词分组 / 最长连续序列 / 移动零）清零前不加新题；题单按顺序推进
- C 轨每题必须：**首写（限时）→ 复盘 → 隔两天闭卷重写**
- STAR 故事库（`docs/B1-前端八股考点.md` K 节）从 Day 4 起就可以陆续填，别拖到冲刺
- **简历即考纲**：每天 A 轨末尾挑简历上的一条词讲 2 分钟；复盘日逐条念一遍（见 `docs/全轨-简历映射.md`）。
  **写了却讲不出的词，要么补上、要么从简历删掉** —— 留着赌它不被问，是简历上最大的雷
