# 每日学习计划

> 三条轨道**每天并行**，不是二选一。MyLotion 继续推进，但从「手敲代码」改成「理解流程 + 能讲出来」。

## 每日模板（约 3 小时，可按当天时间缩放到 2 小时）

| 轨道 | 时长 | 做什么 | 产出物 | 完成标准 |
|------|------|--------|--------|----------|
| **A · MyLotion 主线** | 60min | 读我给的实现 / 架构说明 → 理解这套流程 → 写讲稿 | `docs/讲稿/dayNN-*.md` | 能脱稿讲 2 分钟，我追问三个问题不卡壳 |
| **B · 八股** | 60min | 从 `docs/面经考点.md` 挑 3~5 条，**合上答案自己开口讲** | 清单打勾 + 卡壳项回填讲稿 | 每一条都能说出「是什么 + 为什么 + 项目里怎么用」 |
| **C · 手撕** | 40min | 从 `src/interview/` 挑 1 道，**限时 20 分钟**手写，再跑测试 | 代码 + 通过用例 | 不用看参考实现就能写出来 |

**每天固定动作**
1. 打开 `docs/面经考点.md`，今天要过的 3~5 条先划出来
2. 手撕限时开始之前先别看提示
3. 收尾时在下面「打卡表」记一行

## B 轨：八股怎么过

- 清单在 `docs/面经考点.md`，★ 越多越高频，**先过 ★★★**
- 方法：**开口讲**，不要默读。讲不顺 = 不会
- 每条的合格标准：「是什么 → 原理/机制 → 优缺点 → 我项目里怎么用的」
- 高优先级（★★★）：事件循环、闭包、缓存 + hash、跨域、WebSocket vs SSE、hooks 原理、状态管理选型、JWT vs Session
