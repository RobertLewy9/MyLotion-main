## 弹性规则

- 某天没做完 → **整体顺延**，不要跳过；宁可少做一条轨，也别断档
- 每 7 天必有一个**复盘日**（Day 11 / 18 / 30 / 38），只讲不学新东西
- B 轨 ★★★ 的高频条目至少要过 **3 遍**（首次学 / 复盘 / 冲刺）
- C 轨每道题必须做到：**首写（限时）→ 复盘 → 隔两天闭卷重写**
- 阶段五的模拟面试按真实流程来：自我介绍 2min → 项目 15min → 八股 15min → 手撕 20min → 反问
