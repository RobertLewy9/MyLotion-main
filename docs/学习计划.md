# 45 天学习计划

> 目标：前端实习面试。**三条轨道每天并行**——MyLotion 推进理解、八股开口过、手撕限时写。
> 时间轴：Day 1~3 已完成（树操作 + 提及解析）；**Day 4 = 2026-10-13（今天）→ Day 48 = 2026-11-26**，共 45 天。
> 每天约 3 小时：A 轨 MyLotion 60min / B 轨 八股 60min / C 轨 手撕 40min。

## MyLotion 完善路线（代码什么时候写、写到什么程度）

**定位**：MyLotion 是**机制复刻的靶场**——用可测试的纯 TS 复刻 Lotion 的核心机制，
不把 Next.js + Supabase 整套搬过来（所以缓存、SSE、压缩这些用纯函数 + mock 落地）。

**策略**：代码由我产出，你负责「读 → 讲 → 被追问」。**你的产出物是讲稿，不是代码。**

**节奏**：跟着 A 轨走，Day 4-42 滚动补齐，**Day 42 收官**；Day 43-48 冻结代码，只做讲稿与模拟面试。
