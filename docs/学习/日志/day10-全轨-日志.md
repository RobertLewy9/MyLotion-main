### 今天应该能说出的参考结论

- Lotion 是单机自托管的 AI 笔记应用：Vite/React SPA + Hono 单进程 + SQLite + BlockNote + DeepSeek Agent。
- Next.js 的 SSR/RSC、ISR、Server Actions、Vercel/Edge 能力在这个项目里基本没有成为主收益。
- 单机 SQLite、本地文件和原生 `better-sqlite3` 与 Serverless/Edge 不匹配。
- Vite 的收益是构建简单、边界清楚、Hono 统一托管；代价是没有 SSR/SEO，用户信息要客户端引导。
- 需要 SEO、服务端渲染、边缘部署时，反而应该选 Next.js。
